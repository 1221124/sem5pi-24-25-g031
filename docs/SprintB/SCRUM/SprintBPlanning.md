- _UC042 (US6.2.13)_: As an Admin, I want to list/search staff profiles, so that I can see the details, edit, and remove staff profiles.
- _UC052 (US6.3.3)_: As an Admin, I want to obtain a good schedule, not necessarily the best, in useful time to be adopted.
- _UC061 (US6.5.1)_: As a healthcare staff member, I want to see a 3D representation of the hospital/clinic floor. Its description should be imported from a JSON (JavaScript Object Notation) formatted file. The floor must consist of several surgical rooms. Each room must be enclosed by walls and include a door and a surgical table. There should be no representation of the ceiling. If a room is being used at any given time, a 3D model of a human body should be lying on the table. Models can either be created or imported.
- _UC063 (US6.5.3)_: As a healthcare staff member, I want to see the hospital/clinic floor illuminated with ambient and directional light.
